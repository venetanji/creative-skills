# Standalone Comfy Graph M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract the existing graph primitives and builders into an independently installable library while preserving skill/CLI behavior.

**Architecture:** Put the independent project at repository-root `comfy-graph/`, with explicit legacy compatibility imports pointing into `creative_comfy_graph`. Extract primitives first, then Flux/TTS, graph-only post, and LTX; transport and orchestration remain in their existing adapters. Preserve ambient behavior during M1, not a disguised deterministic API rewrite.

**Tech Stack:** Python >=3.11, Hatchling, uv, pytest (development only), standard-library runtime.

**Spec:** `docs/superpowers/specs/2026-09-29-standalone-comfy-graph-design.md` (architecture approved by Gio at 2026-09-29 17:48).

**Execution approval:** Gio confirmed this task-level plan at 2026-09-29 18:03 UTC. Execute all six tasks using the selected supervised subagent method; do not request another design/plan approval.

## Global Constraints

- Distribution `creative-comfy-graph`; import namespace `creative_comfy_graph`; project `comfy-graph/`; own src layout, metadata, README, MIT license, tests, wheel and sdist.
- Python >=3.11; actual Python 3.11 and 3.12 executions are acceptance gates. Zero third-party runtime dependencies; no Torch, ComfyUI, weights, OpenClaw, Easel or transport dependency.
- Preserve every existing builder signature/default/keyword, return dictionary, graph ordering, filenames/output markers, frame rounding, cropping, dimensions and audio trim/mux semantics. No generic replacement API.
- Preserve `seed=None`, current seed-zero inconsistencies, `time.time()`, `LTX_SAGE_ATTENTION`, warnings and swallowed `**_` behavior. Label these ambient dependencies, do not silently change them.
- Keep `core.BASE` mutable and transport in `core.py`; keep `stage_clips_for_concat` in legacy `post.py`. Keep every existing import in `comfy_graph.py` available, including its module aliases.
- One isolated implementation checkout, one implementer then a fresh independent reviewer per task/slice; parent resolves findings and verifies immutable reviewed HEAD before advancing. No concurrent builder writers.
- No product work before plan review. No Easel/client/CLI edits, installed-skill replacement, new remote repo, push, PR, publication, deployment, GPU/render or broad `test_all_workflows.py` execution.
- No source-checkout fetch/write, automatic dependency installation on import, sibling-repo discovery, installed-script fallback or test-only PYTHONPATH. Tests may explicitly load legacy files from a supplied fixture directory, never package source.
- Pure-library tests block network, subprocesses and client-media access without blocking ordinary Python imports. Never invoke existing unsafe image/help/dump paths without boundary mocks.
